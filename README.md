# 🌸 Sora RP Calendar

Лёгкий декоративный мини-календарь для **SillyTavern**. Показывает игровую дату, время и место
прямо над полем ввода — всегда на виду, пока вы пишете сообщение.

```
📅 23.11.2010, пн     ◷ 14:24
        📍 Berry University
```

Расширение **ничего не генерирует**: без LLM, без API-запросов, без токенов, без инжектов в промпт.
Оно только читает локальную историю текущего чата и рисует панель.

## Возможности

- Автоматически берёт **последний актуальный** инфоблок из чата.
- Русские и английские метки: `Date:` / `Дата:`, `Time:` / `Время:`, `Location:` / `Место:` / `Локация:`, `Weather:` / `Погода:`.
- Не зависит от оформления: `[В]`, `©`, markdown (`**Date:**`), HTML-теги, переносы строк, разделители `|` `•` `·` `;`, соседние поля вроде `Known:`.
- Скрытые метки `<!-- [RP_DATE:18.07.2025 11:24] -->` и `<!--tel:time:11:24 18.07.2025-->` задают дату и время одной парой.
- Форматы времени: `14:24`, `14:24:00`, `2:24 PM`, `2:24 вечера`.
- Форматы даты: `23.11.2010`, `23/11/2010`, `2010-11-23`, `23 ноября 2010`, `November 23, 2010`. День недели берётся из блока, а если его нет — вычисляется.
- Три режима: **компактный** (дата + время), **стандартный** (+ место), **раскрытый** (+ погода и исходная строка инфоблока). Переключается кнопкой `›` на панели.
- Своя дата/время у **каждого чата**; корректная работа со свайпами, регенерацией, редактированием и удалением сообщений, группами.
- Если в новом ответе инфоблока нет — остаются прежние значения. Реальное время никогда не подставляется.
- Если данных нет: «Игровое время не найдено».
- Ручное обновление и **ручная установка** времени для нестандартных игр (на каждый чат отдельно).
- Адаптивная панель: на узких экранах уменьшается, длинное место обрезается «…», клавиатура не закрывается при нажатии на кнопки панели.
- **Живые узоры** (можно отключить): сезон по дате — сакура (весна), ромашка (лето), лист (осень), снежинка (зима). Справа — значок по погоде из инфоблока (солнце, луна, облака, дождь, гроза, снег, туман; понимает русские и английские слова), а по времени суток меняются лёгкий оттенок фона (рассвет, день, закат, ночь) и появляются мерцающие звёздочки ночью. Если погоды нет — значок выбирается по времени суток. Сезоны считаются для северного полушария.
- Настройки внешнего вида: режим, цвет текста / рамки / фона, прозрачность фона, цветочный декор.
  По умолчанию цвета берутся из активной темы SillyTavern (светлой или тёмной).

## Установка через GitHub

1. В SillyTavern откройте **Extensions → Install extension**.
2. Вставьте `https://github.com/KiskaSora/RP-Calendar` и установите расширение.
3. Перезагрузите страницу SillyTavern и откройте чат.

Обновление: **Extensions → Manage extensions → Update** (значок обновления рядом с расширением).

### Ручная установка

Скопируйте папку целиком в:

- `SillyTavern/data/<ваш-пользователь>/extensions/Sora-RP-Calendar/` (для себя) или
- `SillyTavern/public/scripts/extensions/third-party/Sora-RP-Calendar/` (для всех),

и перезагрузите страницу.

> Требуется SillyTavern **1.12.0** или новее (используется `SillyTavern.getContext()`).

## Настройки

**Extensions → Sora RP Calendar**

| Параметр | Описание |
|---|---|
| Показывать календарь | Включает/выключает панель. При выключении все обработчики событий снимаются. |
| Режим | Компактный / стандартный / раскрытый. |
| Цвет текста, рамки, фона | «Сброс» возвращает цвет темы. Цвет рамки также красит иконки. |
| Прозрачность фона | 0–100 %. |
| Цветочный декор | Узоры по краям панели. |
| Оформление узоров | «Книжная гравюра» (по умолчанию) или «Перламутр». Сезоны, части суток и погода используют отдельные прозрачные PNG из `assets/`. |
| Обновить из истории | Принудительно пересканировать чат. |
| Ручная установка | Дата, время и место для текущего чата. Пустые поля берутся из инфоблоков. |

## Как это работает

- Использует `SillyTavern.getContext()` и `eventSource`: `CHAT_CHANGED`, `MESSAGE_RECEIVED`, `MESSAGE_SENT`, `MESSAGE_EDITED`, `MESSAGE_UPDATED`, `MESSAGE_DELETED`, `MESSAGE_SWIPED`, `MESSAGE_SWIPE_DELETED`, `GENERATION_ENDED`, `GROUP_UPDATED`, `APP_READY`.
- Токены стриминга **не отслеживаются** — панель обновляется один раз после готового ответа.
- Сканирование идёт от последнего сообщения к первому и останавливается на первом найденном инфоблоке; разобранные сообщения кэшируются, так что вся история не перечитывается.
- При смене чата кэш и результат сбрасываются до первого сканирования — данные прошлого чата не показываются.
- Ручные значения хранятся в настройках расширения (`extensionSettings`), а не в файлах чатов. Сообщения, инфоблоки, промпты и контекст модели не затрагиваются.
- Все CSS-классы с префиксом `sora-`; конфликтов с темами и другими расширениями быть не должно.
- При повторной загрузке и закрытии страницы старый экземпляр полностью очищается (`window.SoraRPCalendar.destroy()`).

## Если панель выглядит не так

Расширение подстраивается под переменные темы `--SmartThemeBodyColor`, `--SmartThemeBorderColor`, `--SmartThemeBlurTintColor`, `--SmartThemeQuoteColor`.
Если пользовательская тема их не определяет, используются нейтральные запасные цвета, или задайте свои в настройках.

Для тонкой подгонки можно добавить в Custom CSS:

```css
#sora_rp_calendar { margin-bottom: 6px; font-size: 13px; }
```
